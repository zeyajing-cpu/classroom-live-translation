# 课堂实时翻译

一个轻量的课堂网页原型：通过浏览器麦克风识别英文，并逐句显示简体中文译文。

## 使用方式

- 使用最新版 Chrome 或 Edge 打开网页。
- 点击“开始聆听”，并允许麦克风访问。
- 保持网络连接；识别到的英文和中文译文会逐句显示。

## 部署到 GitHub Pages

1. 在 GitHub 创建一个公开仓库。
2. 将本项目文件上传到仓库根目录。
3. 在仓库的 **Settings → Pages** 中选择从部署分支发布，并将目录设为根目录。
4. 等待 GitHub Pages 发布完成后，使用仓库页面提供的网址访问。

## 使用限制与隐私

- 本项目使用浏览器的 Web Speech API；识别能力和可用性取决于浏览器、系统和网络。
- 语音识别由浏览器提供的识别服务处理。翻译通过 MyMemory 在线接口完成。使用时，语音和识别文本可能会被传输给相应服务。
- 在线服务可能有延迟、额度或可用性限制。课堂专有名词和重要信息请核对。
- 麦克风需要用户授权。建议只在已获授课者同意的场景使用。
