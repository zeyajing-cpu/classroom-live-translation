# 多语言课堂实时翻译

[打开在线网页](https://zeyajing-cpu.github.io/classroom-live-translation/) · 支持英语、日语、韩语和德语语音识别，并将识别片段翻译为简体中文。

这是一个轻量的课堂网页原型。网页使用浏览器 Web Speech API 获取语音识别结果，并将识别文本发送给 MyMemory 翻译。第一段临时识别文本会在短暂停顿后翻译；后续临时译文至少间隔 4 秒且识别文本增加一定长度才请求，以节省免费翻译额度。每个定稿片段会立即翻译。客户端会在语音识别意外结束后持续自动重连，重试间隔逐步增加，最长约 30 秒。

## 使用方式

- 使用最新版 Chrome 或 Edge 打开在线网页。
- 选择老师使用的语言，点击“开始聆听”，并允许麦克风访问。
- 保持网络连接；页面会同步显示识别原文和中文译文。

## 费用与服务限制

本项目不调用腾讯云实时语音识别，也不需要部署签名 Worker 或填写云服务密钥。浏览器语音识别和 MyMemory 的可用性、处理位置与免费额度由对应服务提供方决定。语音识别的 Web Speech API 并非所有浏览器都支持；Chrome 等浏览器可能使用在线识别服务，详见 [MDN Web Speech API 文档](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API)。MyMemory 免费接口可能有调用限制，超出后译文可能暂时不可用。页面会降低临时译文请求频率以尽量节省额度，但不会保证零费用或无限使用；请检查服务商最新条款和账号用量。

## 使用限制与隐私

- 麦克风语音由浏览器所采用的识别服务处理。浏览器提供方可能会接收语音，MyMemory 会接收识别出的文本用于翻译。
- 识别延迟和准确度取决于浏览器、网络、口音、设备及环境噪声。课堂专有名词和重要信息请核对。
- 临时识别结果会不断修订；网页节流后再请求译文，因此通常会稍晚于原文出现。浏览器语音识别仍可能因长时间运行、网络或系统策略而停止；网页会持续自动重连，但无法保证识别服务始终在线。
- 课堂使用前请告知授课者和参与者，并取得同意。不要用于处理未经授权的录音或敏感内容。
